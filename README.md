## Задача 1.1. Дробная часть

**Требуется:** отделить от вещественного числа дробную часть и вернуть её.

Необходимо реализовать метод таким образом, чтобы он возвращал только дробную часть числа `x`.

Вещественное число можно преобразовать к целому числу, отбросив дробную часть.

Пример: x = 5.25 Результат: 0.25

**Алгоритм решения:**

1. Создать метод `fraction`, принимающий вещественное число.
2. Преобразовать число `x` к типу `int`, чтобы получить его целую часть.
3. Вычесть полученную целую часть из исходного числа.
4. Полученный результат будет являться дробной частью числа.
5. Вернуть результат.

Необходимо реализовать метод, который принимает символ `x`, представляющий одну из цифр от `'0'` до `'9'`, и возвращает соответствующее число.

Пример: x = '3' Результат: 3

**Алгоритм решения:**

1. Создать метод `charToNum`, принимающий символ.
2. Использовать тот факт, что символы в Java имеют числовые коды.
3. Из кода полученного символа вычесть код символа `'0'`.
4. Получить числовое значение символа.
5. Вернуть результат.

## Задача 1.5. Двузначное

**Требуется:** определить, является ли число двузначным.

Необходимо реализовать метод, который принимает число `x` и возвращает `true`, если число является двузначным.

Пример: x = 32 Результат: true
Пример: x = 516 Результат: false

**Алгоритм решения:**

1. Создать метод `is2Digits`, принимающий целое число.
2. Проверить, находится ли число в диапазоне от 10 до 99.
3. Проверить, находится ли отрицательное число в диапазоне от -99 до -10.
4. Если число попадает в один из указанных диапазонов, вернуть `true`.
5. В остальных случаях вернуть `false`.

## Задача 1.7. Диапазон

**Требуется:** определить, входит ли число в указанный диапазон.

Необходимо реализовать метод, который принимает левую и правую границы диапазона `a` и `b`, а также число `num`.

Метод должен вернуть `true`, если число `num` находится внутри указанного диапазона, включая границы.

Пример:
a = 5  
b = 1  
num = 3  
Результат: true

**Алгоритм решения:**

1. Создать метод `isInRange`, принимающий две границы диапазона и число.
2. Проверить, какая из границ диапазона является большей.
3. Если `a` больше `b`, считать диапазоном значения от `b` до `a`.
4. Если `b` больше `a`, считать диапазоном значения от `a` до `b`.
5. Проверить, находится ли число `num` между найденными границами.
6. Вернуть полученный результат.

## Задача 1.9. Равенство

**Требуется:** проверить равенство трёх чисел.

Необходимо реализовать метод, который принимает три числа и возвращает `true`, если все три полученных числа равны.

Пример:
a = 3  
b = 3  
c = 3  
Результат: true

**Алгоритм решения:**

1. Создать метод `isEqual`, принимающий три целых числа.
2. Сравнить первое число со вторым.
3. Сравнить второе число с третьим.
4. Если оба сравнения возвращают `true`, значит все числа равны.
5. Вернуть полученный результат.

# Задание 2

## Задача 2.1. Модуль числа

**Требуется:** найти модуль числа.

Необходимо реализовать метод, который принимает число `x` и возвращает его модуль.

Если число положительное, оно остаётся без изменений. Если число отрицательное, необходимо вернуть его без знака минус.

Пример: x = 5 Результат: 5
Пример: x = -3 Результат: 3

**Алгоритм решения:**

1. Создать метод `abs`, принимающий целое число.
2. Проверить, является ли число отрицательным.
3. Если число меньше нуля, изменить его знак на противоположный.
4. Если число положительное, оставить его без изменений.
5. Вернуть полученный результат.

## Задача 2.3. Тридцать пять

**Требуется:** определить, делится ли число на 3 или 5.

Необходимо реализовать метод, который возвращает `true`, если число `x` делится нацело на 3 или на 5.

Если число делится одновременно и на 3, и на 5, необходимо вернуть `false`.

Пример: x = 5 Результат: true
Пример: x = 8 Результат: false
Пример: x = 15 Результат: false

**Алгоритм решения:**

1. Создать метод `is35`, принимающий целое число.
2. Проверить, делится ли число одновременно на 3 и на 5.
3. Если число делится на оба значения, вернуть `false`.
4. Проверить, делится ли число только на 3 или только на 5.
5. Если одно из условий выполняется, вернуть `true`.
6. В остальных случаях вернуть `false`.

## Задача 2.5. Тройной максимум

**Требуется:** найти максимальное из трёх чисел.

Необходимо реализовать метод, который принимает три числа `x`, `y`, `z` и возвращает наибольшее из них.

Пример:
x = 5  
y = 7  
z = 7  
Результат: 7

**Алгоритм решения:**

3. Сравнить второе число с `max`.
4. Если второе число больше, записать его в `max`.
5. Сравнить третье число с `max`.
6. Если третье число больше, записать его в `max`.

## Задача 2.7. Двойная сумма

**Требуется:** вычислить сумму двух чисел с дополнительным условием.

Необходимо реализовать метод, который возвращает сумму чисел `x` и `y`.

Пример: x = 5; y = 7  
Результат: 20
Пример: x = 8; y = -1

**Алгоритм решения:**

1. Создать метод `sum2`, принимающий два целых числа.

3. Проверить, находится ли полученная сумма в диапазоне от 10 до 19.
4. Если условие выполняется, вернуть число 20.

## Задача 2.9. День недели

**Алгоритм решения:**

x = 2

## Задача 4.3. Поиск максимального

**Требуется:** найти значение массива с максимальным модулем.

Необходимо реализовать метод, который возвращает элемент массива, значение которого является наибольшим по модулю.

Знак числа при этом необходимо сохранить.

Пример: arr = [1, -2, -7, 4, 2, 2, 5]

**Алгоритм решения:**

## Задача 4.5. Добавление массива в массив

**Требуется:** вставить один массив внутрь другого.

Необходимо реализовать метод, который возвращает новый массив.

arr = [1, 2, 3, 4, 5]

Результат: [1, 2, 3, 7, 8, 9, 4, 5]

**Алгоритм решения:**

1. Создать метод `add`, принимающий два массива и позицию вставки.

3. Скопировать элементы массива `arr` до позиции вставки.
4. Добавить элементы массива `ins` начиная с позиции `pos`.
5. Скопировать оставшиеся элементы массива `arr` после вставленных значений.
6. Вернуть новый полученный массив.
